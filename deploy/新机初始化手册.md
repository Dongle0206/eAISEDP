# eAISEDP 新机部署初始化手册

> **目标机器**：新机（Windows，16GB 内存，C盘 256GB SSD + D盘 1TB）
> **角色**：部署机（Deploy 机），跑后端服务栈
> **配合**：本机（Dev 机）开发，新机部署，浏览器访问
> **预计耗时**：2-3 小时（含等待下载）

---

## 阶段 1：系统准备（15 分钟）

### 1.1 Windows 更新
- 设置 → 更新和安全 → Windows 更新 → 检查更新 → 全部安装 → 重启

### 1.2 启用虚拟化（BIOS）
- 重启进 BIOS（开机按 F2/F10/Del，看主板提示）
- 找 `Intel Virtualization Technology` 或 `SVM Mode` → 改 `Enabled`
- 保存退出

### 1.3 启用 Windows 功能（管理员 PowerShell）
```powershell
# 管理员 PowerShell
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
# 不要立即重启，等下面装完 WSL2 内核再一起重启
```

### 1.4 创建目录结构
```powershell
# 普通 PowerShell
mkdir D:\eaiselp\platform
mkdir D:\eaiselp\data\mysql
mkdir D:\eaiselp\data\minio
mkdir D:\eaiselp\data\nacos
mkdir D:\eaiselp\data\logs
mkdir D:\eaiselp\backups
mkdir D:\eaiselp\deploy
mkdir D:\jdk-17
mkdir D:\maven
```

## 阶段 2：装 JDK 17（15 分钟）

### 2.1 下载
- 访问 https://adoptium.net/temurin/releases/?version=17
- 选 Windows x64 `.zip`（不要 .msi，方便控制路径）
- 解压到 `D:\jdk-17\`，最终路径 `D:\jdk-17\jdk-17.0.11+9\`（版本号可能不同）

### 2.2 配置环境变量（管理员 PowerShell）
```powershell
# 管理员 PowerShell
[System.Environment]::SetEnvironmentVariable("JAVA_HOME", "D:\jdk-17\jdk-17.0.11+9", "Machine")
$old = [System.Environment]::GetEnvironmentVariable("Path", "Machine")
[System.Environment]::SetEnvironmentVariable("Path", "$old;D:\jdk-17\jdk-17.0.11+9\bin", "Machine")
# 关闭 PowerShell，重开验证
java -version
```

应该看到 `openjdk version "17.0.11"` 之类。

## 阶段 3：装 Maven（10 分钟）

### 3.1 下载
- 访问 https://maven.apache.org/download.cgi
- 下载 `apache-maven-3.9.9-bin.zip`
- 解压到 `D:\maven\`

### 3.2 配置环境变量
```powershell
[System.Environment]::SetEnvironmentVariable("MAVEN_HOME", "D:\maven\apache-maven-3.9.9", "Machine")
$old = [System.Environment]::GetEnvironmentVariable("Path", "Machine")
[System.Environment]::SetEnvironmentVariable("Path", "$old;D:\maven\apache-maven-3.9.9\bin", "Machine")
mvn -version
```

### 3.3 配阿里云镜像（**关键**，国内访问 Maven 中央仓库慢）
编辑 `D:\maven\apache-maven-3.9.9\conf\settings.xml`，在 `<mirrors>` 段加：
```xml
<mirror>
  <id>aliyun-public</id>
  <mirrorOf>*</mirrorOf>
  <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```

## 阶段 5：装 WSL2（30 分钟，最容易卡）

### 5.1 下载 WSL2 内核更新包（离线装，绕开 Store）

**用浏览器**打开：
```
https://wslstorestorage.blob.core.windows.net/wslblob/wsl_update_x64.msi
```

下载 `wsl_update_x64.msi`（约 16MB），双击安装。

### 5.2 下载 Ubuntu 离线包
**用浏览器**打开：
```
https://aka.ms/wslubuntu2204
```

下载 `.appx` 文件（约 600MB）。

### 5.3 安装 Ubuntu
```powershell
# 把 .appx 改名为 .zip 解压
Rename-Item Ubuntu.appx Ubuntu.zip
Expand-Archive Ubuntu.zip -DestinationPath D:\WSL\Ubuntu

# 设置 WSL2 为默认
wsl --set-default-version 2

# 启动 Ubuntu 安装
D:\WSL\Ubuntu\ubuntu2204.exe
```

启动后让你设 Linux 用户名密码（**记住密码**）。

### 5.4 验证
```powershell
wsl --list --verbose
# 应看到 VERSION=2
```

## 阶段 6：装 Docker Desktop（30 分钟）

### 6.1 下载
- 访问 https://www.docker.com/products/docker-desktop/
- 下载 Docker Desktop for Windows

### 6.2 安装
- 双击安装，**勾选 "Use WSL 2 instead of Hyper-V"**
- 安装完重启

### 6.3 **关键**：把 Docker 数据迁到 D 盘

WSL2 默认把虚拟磁盘放 C 盘（256GB 会爆）。必须迁：

```powershell
# 管理员 PowerShell
wsl --shutdown
wsl --export docker-desktop-data D:\docker-desktop-data.tar
wsl --unregister docker-desktop-data
wsl --import docker-desktop-data D:\docker\docker-desktop-data D:\docker-desktop-data.tar
del D:\docker-desktop-data.tar
```

### 6.4 配置 Docker 中国镜像加速
Docker Desktop → Settings → Docker Engine，改成：
```json
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://dockerproxy.com",
    "https://docker.mirrors.ustc.edu.cn"
  ],
  "experimental": false
}
```
点 Apply & Restart。

### 6.5 验证
```cmd
docker version
docker run hello-world
```

### 6.6 配置 WSL2 资源限制
新建 `C:\Users\<用户名>\.wslconfig`：
```ini
[wsl2]
memory=12GB
processors=4
swap=4GB
```
这限制 WSL2 最多吃 12GB 内存（保留 4GB 给 Windows）。

## 阶段 9：首次启动验证（30 分钟）

### 9.1 启动基础设施
```cmd
cd /d D:\eaiselp\platform
docker compose up -d
```

等待 MySQL/Nacos/MinIO 启动。

### 9.2 验证基础设施
```cmd
docker ps
# 应看到 3 个容器：mysql、nacos、minio

# 验证 MySQL
docker exec eaiselp-mysql mysql -uroot -proot -e "SHOW DATABASES; USE eaiselp; SHOW TABLES;"

# 验证 Nacos
curl http://localhost:8848/nacos/

# 验证 MinIO
curl http://localhost:9000/
```

### 9.3 打包
```cmd
cd /d D:\eaiselp\platform
mvn clean package -DskipTests
```

### 9.4 启动 runtime 服务
```cmd
java -jar eaiselp-runtime\target\eaiselp-runtime.jar
```

看到 `Started EaiselpRuntimeApplication` 表示启动成功。

### 9.5 验证 API
新开 cmd 窗口：
```cmd
curl http://localhost:8080/api/capability/overview
```

应返回 JSON。

## 阶段 10：与本机协同（10 分钟）

### 10.1 找新机 IP
```cmd
ipconfig
# 记下 IPv4 地址，例如 192.168.1.100
```

### 10.2 在本机访问新机
- 本机浏览器打开 http://192.168.1.100:8080/api/capability/overview
- 应能看到返回

### 10.3 防火墙开放端口
如果本机访问不到，在新机管理员 PowerShell：
```powershell
New-NetFirewallRule -DisplayName "eAISEDP-API" -Direction Inbound -LocalPort 8080,8848,9000,9001,3306 -Protocol TCP -Action Allow
```

## 阶段 11：防火墙/服务自启动（可选）

### 11.1 让 Docker 开机自启
Docker Desktop → Settings → General → 勾选 "Start Docker Desktop when you sign in"

### 11.2 让基础设施开机自启
```cmd
# 创建启动批处理
echo @echo off > D:\eaiselp\deploy\start-all.bat
echo cd /d D:\eaiselp\platform >> D:\eaiselp\deploy\start-all.bat
echo docker compose up -d >> D:\eaiselp\deploy\start-all.bat
echo start "runtime" cmd /k "java -jar D:\eaiselp\platform\eaiselp-runtime\target\eaiselp-runtime.jar" >> D:\eaiselp\deploy\start-all.bat
```

把 `start-all.bat` 放启动文件夹（`Win+R` 输入 `shell:startup`）。

## 常见问题

### Q1: docker compose up 报 "no such file"
**A**：在 `D:\eaiselp\platform` 目录下跑，不是在 deploy 目录。

### Q2: mvn package 拉依赖很慢
**A**：检查 Maven settings.xml 阿里云镜像是否配好（阶段 3.3）。

### Q3: docker pull 很慢
**A**：检查 Docker 镜像加速是否配好（阶段 6.4）。

### Q4: 内存吃满了
**A**：
- 关掉新机不必要的程序（微信、IDE）
- 编辑 `.wslconfig` 限制 WSL2 内存（阶段 6.6）
- 暂时不开 MinIO（M1.0 用不到）

### Q5: 本机访问不到新机 API
**A**：
- 检查新机 IP 是否对（ipconfig）
- 检查防火墙（阶段 10.3）
- 检查两台机是否在同一网段（应该都接同一个路由器）
