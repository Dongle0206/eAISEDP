| 字段 | 值 |
|---|---|
| 编号 | QG-MODULE |

| 日期 | 2026-07-21 |
| 状态 | 强制执行（Mandatory） |
| 来源 | `工程标准-001-Maven模块规范.md` + `ADR-001-模块边界与repackage策略.md` |
| 适用角色 | L1-Reviewer（PR 验收）、L1-QA（手动跑脚本，M1 阶段未接 CI/CD） |

---

## 0. 总则

- 本门禁落地 ADR-001 的 P1/P2/P4 + ES-001 的 C1–C7、C10、C13 等可机器判定的检查项。
- M1 阶段未接 CI/CD，门禁以 **PowerShell 脚本** 形式提供，QA 在 PR 验收时手动跑。
- M2 接 CI/CD 后，本脚本逻辑移植为 GitHub Actions / Jenkins Pipeline step，规则不变。
- **阻断（blocker）**：违反则 PR 必须打回修复。**警告（warning）**：需 L1-SE 书面说明可放行，否则仍打回。

---

## 1. 门禁规则总览

| 规则 | 检查对象 | 关联原则 | 类别 |
|---|---|---|---|
| G1 | 父 POM 的 `pluginManagement/spring-boot-maven-plugin` 不允许含 `<executions>` 段 | P4、ES-C1 | **阻断** |
| G2 | library 模块（common/capability/adapter/data）的 POM 不允许含 `spring-boot-maven-plugin` | P1/P2、ES-C2 | **阻断** |
| G3 | library 模块不允许有 `@SpringBootApplication` 注解的类 | P1、ES-C3 | **阻断** |
| G4 | library 模块不允许配 `@EnableDiscoveryClient` / `@EnableEurekaClient` | P1、ES-C4 | **阻断** |
| G5（附赠）| library 模块 POM 不允许含 `spring-cloud-starter-alibaba-nacos-discovery` 依赖 | P1、ES-C5 | **阻断** |
| G6（附赠）| service 模块（runtime/gateway/auth/observability/admin）的 POM 必须显式含 repackage `<executions>` | P4、ES-C6 | **阻断** |

> G5、G6 不在原任务最小集，但与 G1–G4 同源同机制（P1/P4），一并纳入可显著降低回归概率，QA 一并跑。

---

## 2. 规则详细定义

### 规则 G1 — 父 POM pluginManagement 禁止 executions

**断言**：`pom.xml`（项目根）中 `<pluginManagement>` 段下的 `spring-boot-maven-plugin` 元素内**不得**出现 `<executions>` 子元素。

**违反示例**（M1.0 根因，pom.xml:131-136）：
```xml
<pluginManagement>
  <plugins>
    <plugin>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-maven-plugin</artifactId>
      <executions>
        <execution><id>repackage</id><goals><goal>repackage</goal></goals></execution>
      </executions>
    </plugin>
  </plugins>
</pluginManagement>
```

**类别**：阻断。

### 规则 G2 — library 模块 POM 禁止 spring-boot-maven-plugin

**断言**：以下 4 个模块的 POM（`<build><plugins>` 段）**不得**出现 `<artifactId>spring-boot-maven-plugin</artifactId>`：
- `eaiselp-common/pom.xml`
- `eaiselp-capability/pom.xml`
- `eaiselp-adapter/pom.xml`
- `eaiselp-data/pom.xml`

**类别**：阻断。

### 规则 G3 — library 模块禁止 `@SpringBootApplication`

**断言**：以下 4 个模块的 `src/main/java` 下**不得**存在带 `@SpringBootApplication` 注解的 `.java` 文件：
- eaiselp-common、eaiselp-capability、eaiselp-adapter、eaiselp-data

**类别**：阻断。

### 规则 G4 — library 模块禁止 `@EnableDiscoveryClient`

**断言**：以下 4 个模块的 `src/main/java` 下**不得**存在带 `@EnableDiscoveryClient` 或 `@EnableEurekaClient` 注解的 `.java` 文件：
- eaiselp-common、eaiselp-capability、eaiselp-adapter、eaiselp-data

**类别**：阻断。

### 规则 G5 — library 模块 POM 禁止 nacos-discovery 依赖

**断言**：G2 列出的 4 个 library 模块 POM **不得**含 `<artifactId>spring-cloud-starter-alibaba-nacos-discovery</artifactId>` 依赖声明。

**类别**：阻断。

### 规则 G6 — service 模块必须显式 repackage executions

**断言**：以下 5 个 service 模块的 POM（`<build><plugins>` 段）**必须**含 `spring-boot-maven-plugin` 且其下**必须**含 `<executions>` 子元素（含 repackage execution）：
- eaiselp-runtime、eaiselp-gateway、eaiselp-auth、eaiselp-observability、eaiselp-admin

**类别**：阻断（P4 落地后，service 不能再依赖父 POM pluginManagement 自动触发，必须自显式）。

## 3. 通过/失败判据

| 门禁结果 | 判据 | 后续动作 |
|---|---|---|
| **全 PASS** | G1–G6 全部通过 | PR 可进入人工评审下一阶段 |
| **任一 FAIL（阻断）** | G1–G6 任一失败 | PR **必须打回**给 L1-Dev 修复，修复后重跑全部门禁 |
| **任一 WARN（警告）** | 当前规则集无警告项（G1–G6 均阻断），预留扩展位 | — |

**重新跑规则**：修复后**必须重跑全部 G1–G6**，不可只跑失败的那一条（防止修复引入新违规）。

## 4. 可执行 PowerShell 脚本（Windows 原生，不依赖 bash）

### 4.1 使用方法

```powershell
# 在项目根（含 pom.xml 的目录）下执行
powershell -ExecutionPolicy Bypass -File .\docs\架构文档\质量门禁-模块边界.ps1
# 或直接粘贴脚本到 PowerShell 终端运行
```

退出码语义：
- `0`：全部门禁通过
- `1`：至少一条阻断规则失败

脚本输出：每条规则打印 `[PASS]` / `[FAIL]`，失败时附文件路径与命中行，最后打印汇总表。

### 4.2 脚本内容

> 建议保存为 `D:\AI\mywork\platform\docs\架构文档\质量门禁-模块边界.ps1`，与本 md 同目录。下面是脚本全文。

```powershell
<#
.SYNOPSIS
  模块边界质量门禁（编译期）—— 落地 ADR-001 P1/P2/P4 + ES-001。
.DESCRIPTION
  在项目根执行。检查 G1–G6 共 6 条规则，任一阻断失败退出码 1。
  M1 阶段 QA 手动跑；M2 接 CI/CD 后移植为 pipeline step。
.NOTES
  仅依赖 Windows PowerShell 5.1+（系统自带），不依赖 git bash。
#>

param(
    [string]$Root = (Get-Location).Path
)

$ErrorActionPreference = 'Stop'
$failures = @()

function Test-Rule {
    param(
        [string]$Id,
        [string]$Desc,
        [scriptblock]$Check
    )
    Write-Host ""
    Write-Host "===== $Id : $Desc =====" -ForegroundColor Cyan
    try {
        $result = & $Check
        if ($result.Passed) {
            Write-Host "[PASS] $Id" -ForegroundColor Green
            if ($result.Detail) { Write-Host "      $($result.Detail)" -ForegroundColor DarkGray }
            return $true
        } else {
            Write-Host "[FAIL] $Id" -ForegroundColor Red
            Write-Host "       $($result.Reason)" -ForegroundColor Red
            if ($result.Evidence) {
                Write-Host "       命中证据：" -ForegroundColor Red
                $result.Evidence | ForEach-Object { Write-Host "         $_" -ForegroundColor Red }
            }
            $script:failures += $Id
            return $false
        }
    } catch {
        Write-Host "[ERROR] $Id 检查脚本异常：$($_.Exception.Message)" -ForegroundColor Magenta
        $script:failures += "$Id(脚本异常)"
        return $false
    }
}

# ---- 辅助：把多行 XML 文本压成单行，便于正则跨行匹配 ----
function Get-PomFlatText {
    param([string]$Path)
    if (-not (Test-Path $Path)) { return $null }
    return ((Get-Content $Path -Raw) -replace '\s+', ' ')
}

# ---- 模块清单 ----
$libraryModules = @('eaiselp-common', 'eaiselp-capability', 'eaiselp-adapter', 'eaiselp-data')
$serviceModules = @('eaiselp-runtime', 'eaiselp-gateway', 'eaiselp-auth', 'eaiselp-observability', 'eaiselp-admin')

# ============================================================
# G1：父 POM pluginManagement/spring-boot-maven-plugin 禁止 executions
# ============================================================
Test-Rule -Id 'G1' -Desc '父 POM pluginManagement 内 spring-boot-maven-plugin 禁止 executions' -Check {
    $parentPom = Join-Path $Root 'pom.xml'
    if (-not (Test-Path $parentPom)) {
        return @{ Passed = $false; Reason = "父 POM 不存在：$parentPom" }
    }
    $flat = Get-PomFlatText -Path $parentPom
    # 提取 pluginManagement 段
    $pmMatch = [regex]::Match($flat, '<pluginManagement>(.*?)</pluginManagement>')
    if (-not $pmMatch.Success) {
        return @{ Passed = $true; Detail = 'pluginManagement 段不存在（无 repackage 全局配方风险）' }
    }
    $pm = $pmMatch.Groups[1].Value
    # 在 pluginManagement 段内找 spring-boot-maven-plugin 块
    $pluginMatch = [regex]::Match($pm, '<plugin>\s*<groupId>\s*org\.springframework\.boot\s*</groupId>\s*<artifactId>\s*spring-boot-maven-plugin\s*</artifactId>(.*?)</plugin>')
    if (-not $pluginMatch.Success) {
        return @{ Passed = $true; Detail = 'pluginManagement 内未声明 spring-boot-maven-plugin' }
    }
    $pluginBody = $pluginMatch.Groups[1].Value
    if ($pluginBody -match '<executions>') {
        $line = (Select-String -Path $parentPom -Pattern '<executions>' -SimpleMatch | Select-Object -First 1).LineNumber
        return @{
            Passed  = $false
            Reason  = 'pluginManagement/spring-boot-maven-plugin 内含 <executions> 段（ADR-001 P4 根因）'
            Evidence = @("pom.xml:$line 命中 <executions>")
        }
    }
    return @{ Passed = $true; Detail = 'pluginManagement/spring-boot-maven-plugin 仅含 configuration，无 executions' }
}

# ============================================================
# G2：library 模块 POM 禁止 spring-boot-maven-plugin
# ============================================================
Test-Rule -Id 'G2' -Desc 'library 模块 POM 禁止 spring-boot-maven-plugin' -Check {
    $violations = @()
    foreach ($m in $libraryModules) {
        $pom = Join-Path $Root "$m\pom.xml"
        if (-not (Test-Path $pom)) {
            $violations += "$m\pom.xml 不存在"
            continue
        }
        $line = (Select-String -Path $pom -Pattern 'spring-boot-maven-plugin' -SimpleMatch |
                 Where-Object { $_.Line -notmatch '^\s*<!--' } | Select-Object -First 1)
        if ($line) {
            $violations += "$m\pom.xml:$($line.LineNumber) 命中 spring-boot-maven-plugin"
        }
    }
    if ($violations.Count -gt 0) {
        return @{ Passed = $false; Reason = 'library 模块 POM 含 spring-boot-maven-plugin（P1/P2）'; Evidence = $violations }
    }
    return @{ Passed = $true; Detail = ($libraryModules -join ', ') + ' 全部无 spring-boot-maven-plugin' }
}

# ============================================================
# G3：library 模块禁止 @SpringBootApplication
# ============================================================
Test-Rule -Id 'G3' -Desc 'library 模块禁止 @SpringBootApplication 注解类' -Check {
    $violations = @()
    foreach ($m in $libraryModules) {
        $src = Join-Path $Root "$m\src\main\java"
        if (-not (Test-Path $src)) { continue }
        $hits = Get-ChildItem -Path $src -Recurse -Filter *.java |
                Select-String -Pattern '@SpringBootApplication' -SimpleMatch
        foreach ($h in $hits) {
            $rel = Resolve-Path -Relative $h.Path
            $violations += "$m\$rel:$($h.LineNumber) @SpringBootApplication"
        }
    }
    if ($violations.Count -gt 0) {
        return @{ Passed = $false; Reason = 'library 模块含 @SpringBootApplication 类（应删除 Application 类，端点由 host 接管）'; Evidence = $violations }
    }
    return @{ Passed = $true; Detail = '4 个 library 模块均无 @SpringBootApplication' }
}

# ============================================================
# G4：library 模块禁止 @EnableDiscoveryClient / @EnableEurekaClient
# ============================================================
Test-Rule -Id 'G4' -Desc 'library 模块禁止 @EnableDiscoveryClient / @EnableEurekaClient' -Check {
    $violations = @()
    foreach ($m in $libraryModules) {
        $src = Join-Path $Root "$m\src\main\java"
        if (-not (Test-Path $src)) { continue }
        $hits = Get-ChildItem -Path $src -Recurse -Filter *.java |
                Select-String -Pattern '@EnableDiscoveryClient|@EnableEurekaClient'
        foreach ($h in $hits) {
            $rel = Resolve-Path -Relative $h.Path
            $violations += "$m\$rel:$($h.LineNumber) $($h.Line.Trim())"
        }
    }
    if ($violations.Count -gt 0) {
        return @{ Passed = $false; Reason = 'library 模块不应注册服务发现（自身不启动，注册由 host 承担）'; Evidence = $violations }
    }
    return @{ Passed = $true; Detail = '4 个 library 模块均无服务发现注解' }
}

# ============================================================
# G5：library 模块 POM 禁止 nacos-discovery 依赖
# ============================================================
Test-Rule -Id 'G5' -Desc 'library 模块 POM 禁止 spring-cloud-starter-alibaba-nacos-discovery 依赖' -Check {
    $violations = @()
    foreach ($m in $libraryModules) {
        $pom = Join-Path $Root "$m\pom.xml"
        if (-not (Test-Path $pom)) { continue }
        $line = (Select-String -Path $pom -Pattern 'spring-cloud-starter-alibaba-nacos-discovery' -SimpleMatch |
                 Where-Object { $_.Line -notmatch '^\s*<!--' } | Select-Object -First 1)
        if ($line) {
            $violations += "$m\pom.xml:$($line.LineNumber) 命中 nacos-discovery 依赖"
        }
    }
    if ($violations.Count -gt 0) {
        return @{ Passed = $false; Reason = 'library 模块不应依赖 nacos-discovery（与 G4 同源，自身不注册）'; Evidence = $violations }
    }
    return @{ Passed = $true; Detail = '4 个 library 模块 POM 均无 nacos-discovery 依赖' }
}

# ============================================================
# G6：service 模块必须显式 repackage executions
# ============================================================
Test-Rule -Id 'G6' -Desc 'service 模块 POM 必须显式声明 spring-boot-maven-plugin + repackage executions' -Check {
    $violations = @()
    foreach ($m in $serviceModules) {
        $pom = Join-Path $Root "$m\pom.xml"
        if (-not (Test-Path $pom)) {
            $violations += "$m\pom.xml 不存在"
            continue
        }
        $flat = Get-PomFlatText -Path $pom
        # 必须含 spring-boot-maven-plugin（在 <build><plugins> 段，非 pluginManagement）
        if ($flat -notmatch '<artifactId>\s*spring-boot-maven-plugin\s*</artifactId>') {
            $violations += "$m\pom.xml 缺 spring-boot-maven-plugin 声明"
            continue
        }
        # 必须在该 plugin 块内含 executions + repackage goal
        $pluginMatch = [regex]::Match($flat, '<plugin>\s*<groupId>\s*org\.springframework\.boot\s*</groupId>\s*<artifactId>\s*spring-boot-maven-plugin\s*</artifactId>(.*?)</plugin>')
        if (-not $pluginMatch.Success -or $pluginMatch.Groups[1].Value -notmatch '<executions>') {
            $violations += "$m\pom.xml spring-boot-maven-plugin 缺 executions（P4 后父 POM 不再触发，必须自显式）"
            continue
        }
        if ($pluginMatch.Groups[1].Value -notmatch '<goal>\s*repackage\s*</goal>') {
            $violations += "$m\pom.xml executions 内缺 repackage goal"
        }
    }
    if ($violations.Count -gt 0) {
        return @{ Passed = $false; Reason = 'service 模块 POM 未显式配 repackage（P4 落地后阻断）'; Evidence = $violations }
    }
    return @{ Passed = $true; Detail = '5 个 service 模块均显式含 repackage executions' }
}

# ============================================================
# 汇总
# ============================================================
Write-Host ""
Write-Host "================= 门禁汇总 =================" -ForegroundColor Yellow
$total = 6
$passed = $total - $failures.Count
Write-Host ("PASS: {0}/{1}    FAIL: {2}" -f $passed, $total, $failures.Count) -ForegroundColor $(if ($failures.Count -eq 0) { 'Green' } else { 'Red' })
if ($failures.Count -gt 0) {
    Write-Host "失败规则: $($failures -join ', ')" -ForegroundColor Red
    Write-Host "结论: PR 必须打回，L1-Dev 修复后重跑全部 G1–G6" -ForegroundColor Red
    exit 1
} else {
    Write-Host "结论: 全部门禁通过，可进入人工评审" -ForegroundColor Green
    exit 0
}
```

### 4.3 脚本设计说明

- **不依赖 bash**：纯 PowerShell cmdlet（`Select-String` / `Get-ChildItem` / `[regex]`），Windows 10+ 自带 PowerShell 5.1 即可跑。
- **XML 跨行匹配**：用 `Get-PomFlatText` 把空白压成单空格，再用正则跨行取 `<plugin>...</plugin>` 块，避免 XML 缩进差异导致误判。
- **注释行排除**：`Where-Object { $_.Line -notmatch '^\s*<!--' }` 排除 XML 注释行，防止被注释的旧配置误判。
- **退出码**：脚本退出码 0/1 供后续 CI 流水线直接消费（M2 接 CI 时用 `$LASTEXITCODE` 判定）。
- **可扩展**：`Test-Rule` 是统一框架，新增规则只需加一个 `Test-Rule` 块，无需改汇总逻辑。
