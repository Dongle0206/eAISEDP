## 一、密钥与凭据（阻断级）

### 1.1 JWT_SECRET

| # | 检查项 | 操作 | 状态 |
|---|--------|------|------|
| 1 | 生产环境 JWT_SECRET 已通过环境变量注入 | 生成 ≥32 字节随机密钥：`openssl rand -base64 48` | ❌ 待操作 |
| 2 | JWT_SECRET 不等于默认值 `dev-placeholder-...` | 检查启动日志无 "JWT_SECRET 未设置，使用默认值" | ❌ 待确认 |
| 3 | JWT_SECRET 未写入 git / 代码 / 配置文件 | 只存在于环境变量或密钥管理服务 | ❌ 待确认 |
| 4 | auth 和 runtime 使用相同的 JWT_SECRET | 两个服务都能正常校验对方签发的 token | ❌ 待确认 |

**操作示例（部署机）：**
```bat
:: 生成密钥（PowerShell）
[Convert]::ToBase64String((1..48 | ForEach-Object { Get-Random -Maximum 256 }))

:: 设置环境变量（系统级，永久）
setx JWT_SECRET "生成的密钥" /M

:: 或在启动脚本中设置（会话级）
set JWT_SECRET=生成的密钥
```
