# 战略地图 — 智能化软件工程服务转型（L3）

> 战略ID: STR-001 | 状态: active | 负责人: 平台Owner
> 数据契约: markdown（未来由平台 t_strategy 承载，字段对齐）

## 1. 战略定位

**公司背景**：软件 IT 服务公司，现有商业模式以人力密集型项目交付为主。

**转型方向**：从"卖人天"转向"卖智能化软件工程能力"——以 eAISEDP 平台 +
多智能体协作体系为核心资产，交付效率从人月级压缩到小时级。

## 2. 战略目标（KPI）

| KPI | 现状 | 目标(1y) | 衡量方式 |
|-----|------|---------|---------|
| 单项目交付周期 | 人月级 | 天级（典型中小项目） | 平台 Case 数据 |
| 单项目人力投入 | N 人月 | ≤ 0.3N | 项目工时 vs 传统基线 |
| 交付质量（缺陷逃逸率） | 基线 | 下降 50% | QA 门禁拦截率 + 生产缺陷数 |
| 平台化收入占比 | 0% | 首批商用客户 ≥ 1 | 商业合同 |
