## 技术要点（Dev 直接照做）

1. **实现**：`eaiselp-adapter` 新增 `MockMCPProvider`（@ConditionalOnProperty eaiselp.adapter.mcp.provider=mock）实现既有 `MCPAdapter` SPI（registerTool/invokeTool/listTools 全走它）；数据 `ConcurrentHashMap<Long tenantId, Map<String,数据>>` 内存分桶（AC 租户隔离）；9 工具启动时注册（Jira: create_issue/list_issues/get_issue；Confluence: create_page/get_page/search_pages；GitLab: create_issue/create_mr/list_mrs——GitLab create_issue 与 Jira 同名加前缀区分：`jira.create_issue` / `gitlab.create_issue` 命名空间式工具名）
2. **MCPController**：既有 /invoke /tools 复用零改动（SPI 多态）；若现有装配是 Http 优先，改按 provider 条件装配（读现有 @ConditionalOnProperty 写法对齐）
3. **契约回环**：单测直接 new HttpMCPAdapter 指向 Mock（本地 HTTP 或进程内直调 Mock 校验 JSON-RPC 2.0 结构：jsonrpc/method/params/id/result/error 字段齐全）——按现有 HttpMCPAdapterTest 模式扩展；Mock 的 invokeTool 返回值即 result 字段
4. **前端 mcp.html**：目录卡片（按 source 分组：jira/confluence/gitlab）+ 试调用（工具选中后按 schema 动态生成输入框）+ 结果 `<pre>` 转义 + 折叠原始报文；全部 esc
5. **边界**：内存态重启即清（AC 已定）；invoke 走既有 30/min 限流与 adapter:view 权限零新增；无 DDL 无权限 seed
6. **测试**：Mock 工具集单测（注册元数据/三源调用/租户隔离/参数校验错误结构/__mock 标识）+ 契约回环 + MCPController 既有测试回归
