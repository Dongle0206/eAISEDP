## 2. AC 抽验结论（代码级可达，4/4 通过）

### AC-F1.4 埋点数据链（t_derivation.gate_result 四支写入） — 通过
唯一写入点 `OrchestrationService.markGateResult`（按 derivationId 精准 UPDATE，失败仅 ERROR 不碰主流程）。四支接线齐全（`OrchestrationService.java:651-718`）：
| 分支 | 行号 | 写入值 |
|---|---|---|
| FAIL + fail_action=warn 放行 | :660 | FAIL_WARN |
| FAIL 超重做上限终判失败 | :674 | FAIL |
| FAIL 打回重做 | :689 | FAIL |
| PASS | :712 | PASS |
| LLM 未输出判定（gate=null） | :707-710 | 不写，保持 NULL |
