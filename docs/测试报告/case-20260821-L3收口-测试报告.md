1. **验收的磁盘核对基准必须是 tasks.md 任务全集，而非编排者交付摘要**：本次 T16（strategy-board 改造）在"双 Dev 后端 36 文件+前端 3 页"的摘要里不存在、在 tasks.md T0~T18 里正式存在，Reviewer 以摘要为核对基准放行、QA 以任务全集核对即抓出。沉淀规则：QA/Reviewer 的 §0 磁盘核对先 `grep '^### T\d' tasks.md` 拿任务全集，再逐条对 git diff——摘要与清单的差集就是漏检高发区。
