1. **口径表类 AC 的复核法：把 PRD 口径表逐行翻译成"构造值→断言值"对照表再核源码**——本例 F3 的 ceil/窗口/边界（恰 7 天、+60s）若只看用例名"四租户口径"会漏边界行；逐行对照才发现锚点 5 专门覆盖恰等/超窗，且 +1ms 不可构造已有 +60s 替代约定（SE §9.1.5）。凡 PRD 给了"QA 构造示例"列的，验收时必须逐行打勾。
